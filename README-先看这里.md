# HONESTMIX Headphone 0.6.10 · 候选开发版

Windows x64 耳机矫正工具，提供独立 EXE 与 VST3。此说明对应当前候选源码；最终可交付状态由包内 evidence/delivery.json、四份原生QA报告、外部VST3记录及冻结 SHA 清单决定。

## 使用

1. 运行 client/HONESTMIX Headphone.exe，在独立客户端的音频菜单选择设备。VST3 用户将整个 plugin/HONESTMIX Headphone.vst3 目录放入自己的插件目录后重新扫描；先保存工程、关闭宿主并备份旧版。
2. 点击玻璃屏上方的型号浅条（更换型号）打开档案库。按品牌或完整型号搜索，再回车、双击或点击 USE HEADPHONE。无匹配时不能应用；BACK 或 Esc 返回。加载状态与失败提示以真实后台处理状态显示；失败时旧档案保持激活，可重新选择重试。
3. 右侧推子控制 0–200%，步长 0.5%。68×24 的大推子帽采用高阻尼相对拖动，按下不会跳到鼠标位置；Shift 微调，拖动中按下或松开 Shift 不应改变已有数值。双击恢复 100%，Home/End 到 0/200%，方向键或滚轮作半步调整，下方百分比可编辑。
4. COMPARE / 原声对比临时将 Correction 矫正阶段切到 0%，再次点击恢复之前比例。主界面不再堆叠 STEREO 与重复 A/B 控件；右键高级菜单保留旧工程 reference filters 的 host 参数兼容，普通界面不把高通或低架近似称为真实手机/车载重现。legacy 模式保持独立，0% 不会自动清除。
5. TEMPO / 节拍时间打开内嵌时间助手。插件适合监听链路，最终导出时按工程工作流旁通耳机矫正，避免将监听处理写入成品。超过 100% 为外推，留意实际输出峰值。

## 界面与图表

界面基准 1000×480，保持 25:12 比例，当前尺寸范围 900×432 至 3000×1440。主动作使用英文主行与中文副行，控件使用可读原生字体，文字、刻度、曲线和控件按当前尺寸绘制。离屏多尺寸截图用于核对布局，不能替代真实 Windows DPI 与商业宿主验收。

ESTIMATED / 预计频响主图 = 档案原始耳机测量的相对dB + 20log10(|实际Correction复数响应|)。相对参考固定为原始测量在1kHz的电平，各校正档位不重新归一化。0%显示原始测量；100%显示叠加完整校正后的预计耳机频响，保留目标、滤波截断、相位与测量残余；100–200%按实际复数混合计算，不强制拉平。灰虚线为Harman2018参考目标。图表是档案模型估算，不能代替个人耳边声压或听力测量。

在同一档案、采样率的稳定状态下，令 t=degree/100，当前FIR复响应为H(f)、对齐dry延迟为D样本，则G(f)=(1-t)·exp(-j·2πfD/Fs)+t·H(f)。200%是2·wet-dry，不代表更准确，不能用dB乘百分比代替复数混合。主图不包含后级旧版参考滤镜；启用这些滤镜或处理器未准备好时隐藏主图，旁路显示原始测量。

例如某频点“+8dB est.”表示预计耳机响应比原始测量的1kHz参考高8dB，不是全局音量、该频点滤波增益或实测声压。同一档案与采样率稳定后，该频点实际滤波增益 = 当前预计值 − 同频点0%原始测量值。

图表滤波响应来自双精度FFT，频率间隔不大于1Hz；悬停使用同一不可变快照的精确DTFT。仅显示原测量支持的20–19955.54Hz且低于Nyquist的范围，不向外推算；纵轴±24dB，越界有提示，悬停保留实际值。参数平滑与档案切换是时变过程，图表不是逐样本频谱测量。悬停主图时曲线渐入，离开后渐隐；100%正常响应使用绿色。Reduce motion使悬停显示立即切换，并冻结星空、跟随点及拖尾动态。

OUT PK +x.x dBFS提示输出样本峰值超过0dBFS，并保持1.5秒。它是音频输出电平提示，与主图dB est.含义不同；不测量采样点之间的true peak，也不提供限幅、自动衰减或削波保护。请在上游预留电平余量。

参数有 20ms 平滑。档案切换由 worker 准备实际采样率 IR，再执行真实 warmup 与显式 20ms fade；请求型号与当前激活型号分开，不能把 LOADING 当作声音已经切换。

## TEMPO 时间助手

HOST 持续读取宿主的 double BPM，保留小数；无有效来源、过期或超出可计算范围时分别提示。独立版没有宿主速度时默认 MANUAL，不伪造 HOST 120。手动有效范围 1–1000 BPM，非法输入不计算。切换来源不会修改宿主速度或音频。

四分音符时长 q=60000/BPM 毫秒。PRE DELAY 为 q/32、q/16、q/8；REVERB 的 Room、Plate、Hall 为 q/2–q、2q–4q、4q–8q；COMP RELEASE 的 Fast、Medium、Slow 为 q/16–q/8、q/4–q/2、q–2q。DELAY 的 1/n 为 4q/n；DOTTED 乘 1.5，TRIPLET 乘 2/3，仅作用于音符 Delay 列。建议时长不是实测 RT60 或通用最佳值。

## 完整 VST3 安装与回滚

先保存工程并关闭宿主。不要只拷贝 Contents 中的单个二进制，必须安装整个 plugin/*.vst3 目录。保守安装脚本只处理你显式给出的目录，不修改宿主/系统扫描配置，不控制正在运行的DAW。例：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-VST3.ps1 -DestinationRoot "$env:LOCALAPPDATA/Programs/Common/VST3" -HostClosed
```

脚本先核对发行清单，复制到新 staging 并逐文件验证，再把同名旧 bundle 移到扫描目录以外的备份区，最后安装新 bundle；不会删除文件。请手动让宿主扫描你选择的目录。备份默认在 LocalAppData/HONESTMIX/plugin-backups，目标和备份必须同盘且互不包含；若使用D盘自定义插件目录，请显式指定同盘扫描范围外的 -BackupRoot。

安装完成会打印 install-receipt.json 的完整路径。关闭宿主后，运行 `Rollback-VST3.ps1 -Receipt "该回执路径" -HostClosed`；脚本核对已安装文件未改变，把新版归档在扫描目录以外，再恢复旧版。没有旧版时移出新版。用户改动过 bundle 时拒绝回滚覆盖。旧版与新版都保留，不自动清理备份。

仅运行脚本或复扫无法修复DOMAIN/TLS/API/UDP问题。HTTPS域名、证书、DNS或备案条件未完成时应保留准确错误，先修真实节点；不要靠反复重装、切换发起者或改成公网HTTP绕过验证。
